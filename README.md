# Chinese New Year E-Card Website

## Project Overview

The Chinese New Year E-Card Website is an interactive web application developed using HTML, CSS, and JavaScript. It allows users to create personalized digital Chinese New Year greeting cards and share festive wishes with friends, family, and other recipients.

The website provides a festive and user-friendly interface with customizable greeting messages, decorative elements, and interactive features. Users can generate shareable links, copy URLs to their clipboard, and share their e-cards through social media platforms and messaging applications.

## Features

- **Personalized Greetings:** Customize recipient names and Chinese New Year greeting messages.
- **Festive User Interface:** Display traditional Chinese New Year themes, colors, decorations, and animations.
- **Interactive Experience:** Use JavaScript to provide dynamic content and interactive elements.
- **Shareable E-Card Links:** Generate URLs that allow recipients to access personalized greeting cards.
- **Copy Link:** Copy e-card URLs to the clipboard for convenient sharing.
- **Social Media Sharing:** Share greeting messages and e-card links on X (formerly Twitter).
- **Easy Distribution:** Send e-card links through messaging applications, email, and other communication platforms.
- **Responsive Design:** Provide an accessible viewing experience across desktop and mobile devices.

## Technologies Used

- **HTML5:** Structures the website and its content.
- **CSS3:** Implements the visual design, animations, and responsive layouts.
- **JavaScript:** Handles user interactions, greeting customization, URL generation, clipboard operations, and social media sharing.

## Getting Started

### Prerequisites

A modern web browser is required to access the website. No additional software is needed to view the deployed application.

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/cny-e-card.git
   ```

2. Navigate to the project directory:

   ```bash
   cd cny-e-card
   ```

3. Open `index.html` in your web browser.

## How to Use

1. Open the CNY E-Card website.
2. Enter the recipient's name and customize the greeting message.
3. Preview the personalized greeting card.
4. Generate or copy the e-card sharing link.
5. Share the link through X, messaging applications, email, or other supported platforms.
6. Allow recipients to open the link and view the greeting card.

## Deployment

The website can be deployed using GitHub Pages to make it publicly accessible online. Once deployed, users can share the website URL with others.

For personalized e-card sharing, the application can encode greeting details in URL parameters or use a backend service to store and retrieve individual cards.

## Project Objective

This project aims to provide a convenient and engaging way to create and distribute personalized Chinese New Year greetings digitally. It demonstrates practical front-end development skills, including responsive web design, interactive JavaScript functionality, clipboard integration, URL-based data sharing, and social media integration.
